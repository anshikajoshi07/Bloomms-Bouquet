# Bloomms-Bouquet 🌸

**Bloomms Bouquet** is an online flower delivery website built using Java (Servlet, JSP), HTML, CSS, JavaScript, and MySQL.

## 🌼 Features
- About Page
- Gallery Page (Product Display)
- User Logout
- Admin panel for product and order management

## 🛠️ Technologies Used
- Java (Servlet + JSP)
- HTML, CSS, Bootstrap, JavaScript
- MySQL (Database)

## 📁 Project Structure
- `flower_jdbc/` — Java & JSP project files
- Frontend: HTML/CSS/JS/Bootstrap
- Backend: Servlet + JDBC
- Database: SQL Scripts

## 💡 How to Run
1. Import project in Eclipse
2. Setup your database in MySQL
3. Deploy using Apache Tomcat
4. Access via `localhost:8080/your_project_name`
